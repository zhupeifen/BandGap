# BandGap v2.0.2

This corrective release synchronizes the public analysis code with the revised manuscript.

- Corrects fractional-formula detection to inspect unreduced source-formula coefficients.
- Adds regression checks for `CsPb0.5Sn0.5Br3`, `Hg0.7Cd0.3Te`, and `CaTiO3`.
- Recomputes fractional-formula shares and the six-dataset association: Spearman rho = 0.85,
  exact two-sided permutation p = 0.067.
- Reframes fractional-formula share as an operational proxy rather than a physical
  solid-solution label or deterministic mechanism.
- Updates robustness outputs, figures, diagnostics, and terminology to report the
  grouped/random MAE ratio.
- Corrects the Tol dataset provenance: it is third-party data from the Materials Data
  Facility (DOI 10.18126/dp3z-bp06), not generated by the manuscript authors.

`10.5281/zenodo.22102802` and resolves to the latest archived release.
